# References

Primary references used for technical verification:

1. [PostgreSQL Data Definition](https://www.postgresql.org/docs/current/ddl.html) — tables, data types, identity columns, constraints, schemas, views and triggers.
2. [PostgreSQL `CREATE TABLE`](https://www.postgresql.org/docs/current/sql-createtable.html) — primary keys, unique constraints, defaults and identity examples.
3. [PostgreSQL SQL Queries](https://www.postgresql.org/docs/current/queries.html) — query syntax, joins, grouping, sorting and set operations.
4. [PostgreSQL `SELECT`](https://www.postgresql.org/docs/current/sql-select.html) — logical query clauses and result processing.
5. [PostgreSQL Using `EXPLAIN`](https://www.postgresql.org/docs/current/using-explain.html) — scan nodes, joins, estimates and actual execution behavior.
6. [PostgreSQL `EXPLAIN` command](https://www.postgresql.org/docs/current/sql-explain.html) — `ANALYZE`, buffers and machine-readable formats.
7. [PostgreSQL Table Partitioning](https://www.postgresql.org/docs/current/ddl-partitioning.html) — partitioning, pruning and operational trade-offs.
8. [PostgreSQL Transaction Isolation](https://www.postgresql.org/docs/current/transaction-iso.html) — isolation levels, snapshots and serialization failures.
9. [PostgreSQL `COPY`](https://www.postgresql.org/docs/current/sql-copy.html) — bulk loading behavior and client-side `\copy`.
10. [PostgreSQL `VACUUM`](https://www.postgresql.org/docs/current/sql-vacuum.html) — dead tuples, space reuse and `VACUUM ANALYZE`.
11. [PostgreSQL Rule System and Views](https://www.postgresql.org/docs/current/rules.html) — view rewriting and the distinction between rules, functions and triggers.
12. [PostgreSQL Data Types](https://www.postgresql.org/docs/current/datatype.html) — built-in types and type selection.

The transcript is the primary source for lesson order and examples, but authoritative PostgreSQL documentation has priority when semantics conflict.
