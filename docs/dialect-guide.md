# Hướng dẫn chuyển dialect từ SQL Server sang PostgreSQL

Khóa học nguồn sử dụng Microsoft SQL Server và T-SQL. Repository này dùng PostgreSQL làm dialect có thể chạy được. Các khái niệm tương đương được đặt cạnh nhau để người học phân biệt phần SQL portable với phần phụ thuộc vendor.

| SQL Server / T-SQL | PostgreSQL | Ghi chú engineering |
| --- | --- | --- |
| `TOP (10)` | `LIMIT 10` hoặc `FETCH FIRST 10 ROWS ONLY` | Luôn kết hợp truy vấn top-N với `ORDER BY` xác định. |
| `ISNULL(value, fallback)` | `COALESCE(value, fallback)` | `COALESCE` là SQL standard và nhận nhiều hơn hai đối số. Không lặp lại khẳng định rằng một hàm luôn nhanh hơn hàm kia. |
| `GETDATE()` | `CURRENT_TIMESTAMP` / `now()` | `CURRENT_TIMESTAMP` ổn định trong transaction; `clock_timestamp()` có thể thay đổi trong cùng transaction. |
| `IDENTITY` | `GENERATED BY DEFAULT AS IDENTITY` | Với schema PostgreSQL mới, ưu tiên identity column thay cho cú pháp `serial` legacy. |
| `NVARCHAR` | `text` hoặc `varchar` | Chuỗi PostgreSQL là Unicode theo database encoding. Chỉ giới hạn độ dài khi đó là business rule thực sự. |
| `BIT` | `boolean` | PostgreSQL dùng `TRUE` và `FALSE`. |
| `DATEPART` | `EXTRACT` / `date_part` | Kiểu trả về và format khác nhau; ví dụ dùng explicit cast khi cần. |
| `DATEDIFF` | phép trừ timestamp/date hoặc interval arithmetic | Không có một hàm thay thế duy nhất với semantics giống hệt cho mọi đơn vị thời gian. |
| `DATEADD` | `timestamp + interval` | Dùng interval có kiểu rõ ràng, chẳng hạn `INTERVAL '7 days'`. |
| `FORMAT` / `CONVERT` để hiển thị | `to_char` | Khi có thể, hãy giữ việc format ở presentation boundary. |
| `#temp_table` | `CREATE TEMP TABLE` | Temporary table trong PostgreSQL có scope theo session. |
| `CREATE OR ALTER PROCEDURE` | `CREATE OR REPLACE PROCEDURE` | PostgreSQL procedure và function có semantics gọi và transaction khác nhau. |
| `TRY...CATCH` | block `EXCEPTION` của PL/pgSQL | Exception rollback các thay đổi trong block PL/pgSQL hiện tại. |
| clustered index | không có mô hình clustering table hoàn toàn tương đương | PostgreSQL heap table và index có physical behavior khác nhau; `CLUSTER` là thao tác rewrite table, không phải clustered index duy trì vĩnh viễn. |
| columnstore index | không có feature built-in hoàn toàn tương đương | Hãy học row-oriented index, BRIN, materialized view và warehouse design của PostgreSQL thay vì giả định hai feature tương đương. |

## Chính sách sửa lỗi

Các phát biểu trong transcript được xem là giả thuyết cho đến khi được kiểm chứng bằng PostgreSQL documentation hoặc một lab có thể tái hiện. Hành vi phụ thuộc vendor phải được đánh dấu. Kết luận về performance không được trình bày như quy luật tuyệt đối vì quyết định của planner phụ thuộc vào phân phối dữ liệu, statistics, cost settings và hardware.
